# Approved publication assets

The book's current authoritative version is declared in [current-edition.json](../current-edition.json).

For edition 0.5, upload **both exact PDFs** from the approved publication into this folder:

- 0.5/Sorting-Cards-Learner-0.5.pdf
- 0.5/Sorting-Cards-Learner-0.5-BOOKLET-LONG-EDGE-18-SHEETS.pdf

Do not re-export or alter either file. The checksums in the manifest identify the approved originals. When both files arrive on main, the GitHub Actions publisher verifies them and creates the versioned release. New editions go in their own versioned folders; update the single manifest and both files together.

The old 0.3 source is historical, not an editable substitute for 0.5.
